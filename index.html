paymentService.ts

Charges the shopper's card when they check out. PaymentService keeps a queue of pending payments and hands each one to PaymentGateway, which talks to the card processor.

When a charge fails, RetryPolicy decides whether to try again and waits longer after each attempt, up to three tries.

Abstraction

Start high.
Zoom in when you need to.

Code has layers: what a system does, how its parts connect, and the lines that do the work. Most editors only show you the last one. Dim lets you read each layer on its own.

See what a file does before how

Every file opens on a short summary of its purpose and a diagram of its shape: which classes exist and how they connect, which messages go where, or which states it moves through. The code is one click away when you want the details.

  • A plain summary of what each file is for
  • Diagrams chosen to fit the code, never filler
  • Redrawn only when the code changes

FAQ

Questions

Do I need a Claude account?

Yes. Dim runs Claude Code under the hood, so you need the Claude Code CLI signed in. Diagram generation uses Claude Haiku through that same CLI.

Will my VS Code extensions work?

Dim is a fork of VS Code, so extensions, settings, keybindings and themes work the way they do in VS Code.

What does diagram generation cost?

Each file is redrawn only when its contents change. In our use that comes to a few cents per changed file in Haiku usage.

Does Dim hide the code?

Never. The summary and diagrams sit on top of the code, not in place of it. The code is one click away, and going to a definition or a search result opens the code directly.

Why is review all or nothing?

Approving hunks one by one keeps you down at the line level. Dim shows you the shape of the whole change, and you accept it as a whole or reject the files you don't want.
